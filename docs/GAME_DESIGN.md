## 1. 何のゲームか

**放置ゲー / 周回ゲー / テキストのみ / 転生ゲー。**
サッカー選手を5歳から育て、引退したらタイムリープして5歳に戻り、
記憶と経験だけを引き継いで何度もやり直す。

想定プレイ時間は**エンドコンテンツまで100時間〜**。

---

## 2. 一番大事な原則：タイムリープの一貫性

> 「転生、という要素を、タイムリープと捉えたい。つまり、5歳に戻ったとして
> **記憶と経験（技術）以外何も変わってない**、身体能力はただの5歳児、
> いきなり金持ちになったわけでもない、というような要素をちゃんと大事にしたい」

これが世界観の背骨。**ここを崩す実装はしない。**

引き継げるもの / 引き継げないものの線引き:

| 引き継ぐ | 引き継がない |
|---|---|
| 記憶（ゲームの知識・どこへ進めばいいか） | 身体能力（5歳児の体に戻る） |
| 技術の「やり方」を知っていること（習慣熟練） | 筋力・スタミナ・身長 |
| 人脈を**知っている**こと | 人脈そのもの（まだ出会っていない） |
| 未来の出来事を知っていること | 金（親の小遣いからやり直し） |

### 記憶を金に変える、がタイムリープの醍醐味

> 「記憶は引き継いでいるので、その記憶を頼りにして転生してすぐにお金が手に入る
> （**競馬で儲けたとか株でもうけた**＝記憶があれば確実にそれが手に入る、という要素。
> **非現実的なアイテムを拾う**、なども）。転生結晶でそういった要素は買えるということ」

つまり「転生したら金持ちスタート」は**そのままでは世界観違反**で、
「前世の記憶で確実に当たる馬券を知っている」という**理由**を経由して初めて成立する。

転生アップグレードを作るときは、必ずこの形にする:

- ❌「開始資金+50万円」
- ⭕「1998年の有馬記念を覚えている（5歳の春に一度だけ配当を得る）」
- ⭕「あの空き地に落ちている物を知っている」

## 3. 三層構造

本人の言葉:

> 「リアルはマジでとんでもない、**15歳で全てのタイトル獲って全勝、全試合10点取る**
> みたいなレベルになるところまでがマックス。この状態に**15周とか**でなるイメージ。
> そこから**二次転生とかして銀河系、宇宙に行く**イメージ」

```
【第1層】リアル               1周目 〜 約15周目
   ザコ → プロ → 海外 → 「15歳で全タイトル・全勝・全試合10得点」
   ここまでは徹底してリアルな金銭感覚・リアルな成長曲線を守る
        ↓ 二次転生（Ascension）
【第2層】超常                 銀河系ドリームイレブン → 宇宙評議会
   リアルの極限を超えた先。ここからインフレしてよい
        ↓
【第3層】他競技への横展開
   「宇宙規模でも強くなってしまったら、もうサッカーにとどまらず
     他のスポーツも順番に攻略していこう。タイムリープしたとして、
     共有できる部分は共有。新規で鍛えなければいけない部分は鍛える」
```

**第1層をリアルに保つことが最優先。** 既存の cat 15〜18（銀河系・創世神・
宇宙評議会）は削除せず、**第2層＝二次転生の後ろへ退避させる**。

### 並行コンテンツ（選手としての成長とは別軸）

> 「また、並行して**監督とか子供育成**はしたい。**クラブとか代表チームの
> 自分以外のメンバーを強くしていく**のも」

- 監督業
- 子どもの育成（既存の `life.childActive` を発展させる）
- 所属クラブ / 代表チームのチームメイト強化（既存の `LOCAL_CLUB_MATES` の発展形）

これらは「選手としての周回」と**並行して**進む別の軸として設計する。

## 5. 金銭のリアリティ

> 「リアルな金銭感覚。ゲーム的な部分と、リアルな部分をせめぎ合わせて、
> できるだけリアルにしたい（**子供年代のときはほぼ金銭が使えない**が、
> 転生することで一気に使える、など）」

### 子供時代は小遣い制（本人選択）

> 「小遣い制にする（数百円単位）」

- 5〜14歳: 月数百円。道具は基本的に親に買ってもらう形で、性能も限定的
- 15歳〜: バイト解禁（既存の `part_time` が minAge 15 なのは正しい）
- 18歳〜: クリニック主催など（既存のまま）
- プロ契約後: 一気に桁が変わる

**そして、ここに転生アップグレードが刺さる。**
「前世の記憶で確実に儲かる」系を買って初めて、子供時代から大金が動く。
それがタイムリープの醍醐味になる。

## 6. 操作量

> 「基本、連打は要らないゲーム設計にしたい。設定をいじって、
> **どういう練習に重きを置くか**とか、**どういうルートで転生するか**で
> バフを積み上げて何度も転生して強くする、という設計」

プレイヤーがやることは2つだけ:

1. **方針を決める**（何の練習に重きを置くか、どの戦術スタイルか）
2. **ルートを選ぶ**（進路選択、転生時のPOS・体格、どの転生アップグレードを買うか）

### 1周目だけ手動を残す（本人選択）

> 「1週目だけ手動残すが。**1週目は5分とかで終わる**ゲームデザインにしたいなあ」

1周目は手動クリックで「不便さ」を体験させ、転生して自動化を買ったときの
解放感を作る。**ただし1周目は5分で終わらせる。** だからダレない。

> 📌 現状の実測: 5歳4月→22歳4月 = 204ヶ月 = 1倍速で**約3.4分**。
> すでにほぼ達成されている。

## 8. 未解決の論点

### 🔴 100時間をどこで作るか

計算が合っていない。

- 1周目 = 約3.4分（実測）
- 2周目以降は引退が33歳前後まで伸びて 5歳→33歳 = 336ヶ月 = **約5.6分**（1倍速）
- **速度アップを買うと激減する。8倍速なら1周42秒**
- 15周してもリアル層は**1〜2時間**にしかならない

100時間に届かせる道は3つ。どれを採るかで設計が大きく変わる:

| 案 | 中身 | リスク |
|---|---|---|
| A. 周回数を増やす | リアル層15周 → その後も延々と周回。二次転生以降で数百周 | 単調になりやすい |
| B. 1周を長くする | 引退年齢を伸ばす / 1ティックを長くする / やることを増やす | 放置ゲーとしてのテンポが落ちる |
| C. 速度アップの位置づけを変える | 速度は「遅れを取り戻す救済」であって常用前提にしない | プレイヤーの期待とズレる |

**この論点は本人に確認が必要。** 暫定では A + B の混合（周回数で稼ぎつつ、
層が上がるごとに1周の中身を増やす）を想定しておく。

### 「15歳で全タイトル・全勝・全試合10得点」をどう表現するか

現状の `CATEGORIES` は「所属リーグ」の階段でしかない。
リアルの極限を表すには、所属とは別に**個人成績の指標**が要る。
（全勝・全試合10得点を達成した周回数、など）

### Idling to Rule the Gods — 「俺TUEEE感」の参考

**多層プレステージの快感**が参考。本人の言う
「ソフトリセット / ハードリセット / スーパーハードリセット」はこの系譜。

核になっている感覚:

- **前は何十時間かかったところが、今は数分で通り過ぎる**
- リセットするたびに「桁」が変わる。足し算ではなく掛け算で強くなる
- 強くなったことを**過去の自分との比較**で実感させる
  （「1周目は大学で終わった自分が、いまは15歳でJ1にいる」）

→ これは §3 の三層構造と §4 の周回カーブがそのまま対応する。

線形から指数に変えて初めてカーブが成立した。[BALANCE_LOG.md](BALANCE_LOG.md)）。

**まだ実装されていない重要な要素: 過去の自分との比較。**
殿堂（`hallOfFame`）に周回ごとの記録は残っているが、
「前周の自分なら何歳でここに居たか」を見せる導線がない。
俺TUEEE感はここで作れる。

## 11. 追加の方針（2026-11-20 その2）

### 11-1. 🔴 前提の訂正: 時間が流れるだけでは能力は上がらない

本人の認識:
> 「1週目に限らず時間が流れるにつれて能力が上がっていくイメージよね？ なら問題ないが。」

**いまの実装はそうなっていない。**

| 行為 | 能力が上がるか |
|---|---|
| 練習を実行する（手動 or AUTO） | **上がる**（`executeDrillInternal`） |
| 試合が行われる | 上がらない。結果・ファン・資金が動くだけ |
| 時間が経つ | 上がらない |

しかも AUTO の解放条件は「練習の累積」なので、
**1周目に一度もクリックしないと AUTO も永久に解放されない。**
自動計測では1周目のピーク総合力が 0 と記録された（実際に起きた）。

これを踏まえて、どうするかは未決:

| 案 | 中身 |
|---|---|
| A | そのまま。1周目はクリックゲーとして割り切る |
| B | 時間経過でも微量に成長する（放置でも進む）。練習は加速手段にする |
| C | 1周目をもっと短くして、クリックする時間自体を減らす |

> 📌 放置ゲームとして「開いて放置しても何も起きない時間」が最初に来るのは
> 離脱要因になりやすい。B が無難だが、方針の「1周目だけ手動を残す」
> （＝不便を体験させて転生の解放感を作る）と緊張関係にある。

### 11-2. 転生は「勝手に起きる」ではなく「選ぶ」

> 「第二、第三転生が可能だったり、監督とかのモードが解禁されたら、
>   **勝手に転生するのはやめよう**か。**時間の流れがストップして、
>   どの転生をするか選べる**ようにする？」

引退した時点で**時間を止めて、進路を選ばせる**。

```
引退
  ↓ 時間停止
┌─────────────────────────────────┐
│ キャリア終了。次にどうする？              │
├─────────────────────────────────┤
│ ① タイムリープ（ソフトリセット）          │ ← 常時
│ ② 第2転生・輪廻超越（ハードリセット）     │ ← 条件を満たすと出る
│ ③ 第3転生・星辰輪廻                     │ ← 条件を満たすと出る
│ ④ 監督として続ける                      │ ← 解禁後
└─────────────────────────────────┘
```

現状は「引退 → タイムリープ演出 → 5歳へ」の一本道で、
第2転生はタイムリープタブから別途押す形になっている。
**選択肢を1箇所にまとめる。**

### 11-3. 寿命の二階建て

> 「監督モードなどが解禁されたら、それとは別に**人間としての寿命**も
>   考慮しないといけないな。**寿命を延ばすアイテム**も第三転生で実装するかね。
>   **圧倒的ビタミン薬とか超絶医療**とかそういう」

いまの `maxRetireAge`（33〜38歳あたり）は**選手としての寿命**。
監督・育成を入れるなら、その上に**人間としての寿命**が要る。

```
選手寿命   33〜38歳   現役を引退する年齢（既存の maxRetireAge）
    ↓
人間寿命   70〜80歳   ここまで監督・育成・クラブ経営ができる
```

第3転生以降の聖杯アップグレードとして寿命延長を置く。
世界観は §2（タイムリープの一貫性）に従い、
**「記憶があるから手に入る」形にする**:

- ⭕「圧倒的ビタミン薬」— 前世で効くと知っていたサプリを5歳から飲む
- ⭕「超絶医療」— 将来の術式を知っているので早期に手を打てる
- ❌「寿命+20年」のような理由のない数値

### 11-4. 能力カーブをグラフで見たい

> 「能力カーブ、いいね。**カーブグラフで出るといい**ね。」

`npm run measure` の結果を表だけでなくグラフで出す。
周回ごとのピーク総合力・到達カテゴリ・転生の発生点が一目で分かる形にする。

### 11-5. 次のバージョンで本人がテストする

> 「次のバージョンくらいで俺が実際テストして感想言いたいぜ。」

数値調整を続けつつ、**遊べる状態で本番に出す**のを次の区切りにする。

## 12. 実際に遊んだフィードバック（2026-11-20 その3）

本人が本番で1周目をプレイした上での指摘。**ここが当面の実装の優先リスト。**

### 12-1. 1周目はこのままでいい ✅

> 「1週目はこれでいいかも。**公式戦で1勝もできないその惨めさ**っていうものがよく伝わってる。
>   紅白戦の部分とかそういうのもなくてもいいかもしれないね。どうせ勝てないんで、
>   **チュートリアルって感じで、ザクザクっと時間が過ぎて、でも全然勝てない、
>   フォーメーション変えようが何しようが意味ないみたいな状態**で良いと思う。
>   **2周目から本番**というイメージ」

→ §11-1 の「1周目の成長をどうするか」は**解決**。いまのままでよい。
むしろ**何をしても勝てない**ことが1周目の体験価値になっている。
紅白戦など、意味のない選択肢はむしろ削ってよい。

### 12-2. 🔴 転生は人生を全うしてから（最優先）

> 「**一時転生が転生した瞬間にできてしまうっていうのは良くない**、
>   いつ[でも結晶]が常にもらえてしまうっていう状況なので、
>   **基本的にはその人生を全うすることで、また転生ができる**という感じにしたい」

現状はタイムリープタブから**いつでも**転生できる。転生した直後でも押せる。
これだと「キャリアを全うする」意味がなくなり、結晶の価値も薄まる。

**あるべき姿**: 引退（または強制タイムリープ）に到達して初めて転生できる。

> ⚠️ §11-2 の「引退時に時間を止めて転生先を選ぶ」と同じ場所の話。
> 選択肢を引退時に集約すれば、この問題も同時に解決する。

### 12-3. フレーバーテキストを厚くする

> 「転生時のフレーバーテキストとか**エンディング何種類かあるもののフレーバーテキスト**っていうのも
>   しっかり用意してもらいたい。**300文字とかそのぐらい**欲しいところ」

対象:

- `ENDINGS_DEF` 7種それぞれのエンディング文

### 12-4. ライバルとの出会いを描く

> 「ライバルとの対戦っていうのも1周目は絶対勝てないようになってるけども、
>   これも**何かしらライバルの出会いとかそういうものが分かるような状態**だといいな」

1周目に勝てないのはよい。ただし**誰と戦っているのか、なぜ因縁があるのか**が分からない。

### 12-5. 🔴 デートが連打するだけの無意味な行動になっている

> 「デートの機能は、**好感度120でおそらく打ち止め**になってしまうが、
>   ただこれ**連打してもお金が消費されるだけっていう意味のない行動**になっているので、
>   このあたりはちょっと手こ入れをしてもらいたい」

上限に達した後も押せて、金だけ減る。**上限で止める／別の価値を与える**。

### 12-6. 🔴 練習はクリックではなく「同時に実行できる数」にする

> 「2周目から練習というものが解放されて、クリックして体力と精神力を消費することで
>   どんどん能力が上がっていって勝てるようになるという仕組みだけれども、
>   これ2周目から導入されるんであれば、**これクリックでやるっていうのはいなくてもいいかも**。
>   つまり**オートとなっている部分を同時に実行できる練習の数という感じで処理する**ということ」
>
> 「リアル思考ということを考えると、同時にできる練習が増える、
>   またやってない練習の能力が上がらないっていうのはリアル思考とはちょっとかけ離れてはいるけれども、
>   **そこはゲーム的な要素として一つ入れてもいい**のかなと思っている」

**設計の転換点。** 方針「連打は要らない」の具体形がこれ。

```
いま              2周目以降こうする
練習をクリック     練習は常時自動で回る
AUTOは別枠        「同時に実行できる練習の数」が強化の対象
```

プレイヤーが決めるのは「**どの練習を何枠ぶん回すか**」になる。
クリック回数ではなく、枠の配分が戦略になる。

### 12-7. トレーニングの戦術ポイント偏重を根本から見直す

そこを回さないと買えないものがある＝選択の余地がない。

## 14. 解放とリセットの整理（2026-11-20 その4）

### 14-1. 原則

## 15. キャリア年数と関係性の設計（2026-11-20 その5）

### 15-1. キャリア年数は結晶で買う。30歳以降は鈍化して早期引退を促す

> 「**キャリア年数は結晶購入で伸びていく仕組みにしろ。
>   そして30歳以降は能力値の伸びが鈍化して、早期引退のインセンティブに。**」

BALANCE_LOG ⑦⑧⑨で潰れた「上限アップが死んでいる」問題への答え。

```
いま                        これから
33年で上限に届かない          引退年齢そのものを結晶で買う
 → 上限を上げても無意味        → 年数が伸びて初めて上限が意味を持つ
 → 成長率が常に勝つ            → 「成長率＝序盤 / 上限＝終盤」で役割が分かれる
```

さらに **30歳以降は能力の伸びが鈍化**する。
伸びない年を続けるより、さっさと引退して次の周回へ行く方が得になる。
= **早期引退のインセンティブ**。方針「ガンガン転生させる」と噛み合う。

| 要素 | 設計 |
|---|---|
| 引退年齢の基礎 | 低めに置く |
| 引退年齢を伸ばす | **継承結晶のアップグレード**（既存の `iron_body` を主軸に） |
| 30歳以降 | 成長率が急に鈍る。粘っても伸びない |
| プレイヤーの判断 | 「まだ伸びるか / もう転生するか」を毎周考える |

> 📌 これで `maxRetireAge` が「結晶の使い道」として独立した軸になる。
> 上限・成長率・年数の3つが別々の役割を持つ。

### 15-2. 関係性は0に戻るが、そこまでのコストが減る

> 「**絆とか連携の数字はリセット後、「0に戻るがその数字までのコストが減る」仕組みに。**
>   実際タイムリープしたとしたら関係性は0に戻るが、
>   **そこまでにあった好みや考え方の記憶は、また関係性を作るのに役立つ**はず」

§2（タイムリープの一貫性）を保ったまま、周回を重ねた意味も残る形。

```
前世で愛弟子との絆を Lv10 まで育てた
      ↓ タイムリープ
絆は Lv0 に戻る（その子はまだ自分を知らない）
でも「何を言えば響くか」は覚えている
      ↓
Lv10 までのコストが減る
```

対象:

| 要素 | リセット後の扱い |
|---|---|
| 愛弟子との絆（`protegeBonds`） | 0に戻る。過去最高Lvまでのコストが減る |
| チーム連携（`relations.teamChem`） | 同上 |
| 恋愛の好感度（`life.affection`） | 0に戻る。過去最高までデート費用が減る |
| 宿敵との共闘（`rivalCoopUnlocked`） | 0に戻る。再度の達成が楽になる |
| 趣味（`retainedHobbies`） | **引き継ぐ**（頭の中の知識なので消えない） |

実装の形: 周回をまたいで「過去最高値」を保持し、
現在値がそれ以下のあいだはコストに割引率を掛ける。

```
cost = baseCost × (currentLv < pastBestLv ? RELEARN_DISCOUNT : 1.0)
```

§14-2 の判断待ち3件はこれで解決:
- 愛弟子の絆 → リセット（＋再習得割引）
- 宿敵との共闘 → リセット（＋再習得割引）
- 趣味 → 引き継ぐ

## 18. 引退は「年齢」ではなく「契約がなくなったとき」（2026-11-20 その8）

> 「加齢で能力値が下がっていけばカテゴリも下がるし、その上で
>   **能力値が一定を下回るとどこも契約しない＝引退**という扱いにしよう。
>   最初から何歳で強制転生ということではなく」

```
衰えて能力が落ちる
  ↓ 今のカテゴリの要求の72%を下回る
降格（契約打ち切り）
  ↓ さらに落ちる
降格、降格…
  ↓ 最下層でも通用しない（総合力4.5未満）
どのクラブからも声がかからない ＝ 引退
```

- `CONTRACT_KEEP_RATIO = 0.72` … 今のカテゴリに残れる下限
- `CONTRACT_FLOOR_RATING = 4.5` … 最下層でも契約がもらえなくなる総合力
- 年齢80歳は安全弁（衰え緩和を積みきった場合に無限に続かないよう）

`maxRetireAge` による強制引退は廃止。
**自分がどこまで粘るかではなく、周りが評価しなくなったら終わる。**

## 19. 縛りチャレンジの作り直し（2026-11-20 その8）

> 「縛りプレイは**条件到達したら通知**されるようにしてほしいのと、
>   **今やってるチャレンジの条件が出てない**からわからなくてこまる。
>   そして、縛りプレイができるようになるころには**その条件は一瞬で満たせる状態**になってるっぽい」

### 対応済み

ヘッダーの「縛り:CH3」バッジに、目標と達成状況を常時出すようにした。

```
縛り:CH3 現役引退までにJ1リーグへ昇格     ← 挑戦中（赤）
縛り:CH3 🎉 条件達成！                   ← 達成した瞬間（琥珀）
縛り:CH3 ✅ 制覇済                       ← クリア済み（緑）
```
バッジにカーソルを合わせると、制約・目標・報酬の全文が出る。

### 未対応: 難易度が崩壊している

調べた放置ゲームのチャレンジ設計の原則:
- チャレンジ＝**ハンデ付きで目標に到達する**もの
- **十分に進歩した後にクリアできる**難度に置く（退屈にならない範囲で）
- 強くなりすぎを防ぐには逓減かソフトキャップ

いまの実装は**目標が固定値**（`categoryId >= 11` など）なので、
解放される頃には一瞬で満たせる。しかも縛りの中身（道具禁止など）に対して、
**継承結晶の強化はそのまま効く**ので、実質的なハンデになっていない。

直す方向の候補:

### 🔴 設計確定（本人・2026-11-20）

> 「縛り、**周回ボーナスを完全無効にしたらクリアできない**。
>   基本的にはそこまでの強化は引き継がれるもの。
>   ただ、**凄まじい減衰が効くことでなかなかクリアできない**
>   （もっと周回して強化しなければいけない）という仕組み」

**強化は持ち込む。その上で巨大な減衰をかける。**

```
❌ 周回ボーナスを無効化 → 裸になるのでクリア不可能
⭕ 強化は効く + チャレンジ固有の激しい減衰
   → いまの強さでは足りない
   → 通常の周回に戻って強化を積む
   → また挑む
```

これが放置ゲームのチャレンジの回り方。
「クリアできない」こと自体が、通常周回へ戻るインセンティブになる。

実装の形:

| 減衰の対象 | 例 |
|---|---|
| 成長量 | ×0.05〜0.2 |
| 能力上限 | ×0.2〜0.5 |
| 試合戦力 | ×0.3〜0.6 |
| 継承結晶の獲得 | ×0.5（クリア前は旨味を減らす） |

チャレンジごとに減衰の種類と強さを変えると、
「どの強化を積めば突破できるか」がチャレンジごとに違ってくる。

目標そのもの（`categoryId >= 11` など）は変えなくてよい。
**減衰が十分に激しければ、固定値の目標でも十分に遠い。**

## 21. 周回ごとの機能解放（v0.3 / 2026-11-23 実装）

> 「子弟継承は何週かしたら解放にするか？ **2週目の人生でいきなり解放されるより、3週目から**」
> 「**2週目以降で増える機能は1周に1つ**にして、**説明とフレーバーテキスト**をちゃんと出すように」

以前は2周目で全機能がまとめて解放され、何が増えたのか分からないまま
画面だけ複雑になっていた。1周に1つへ分散した。

| 周回 | 解放される機能 |
|---:|---|
| 2 | 🛒 道具・自己投資 |
| 3 | 👥 師弟継承 |
| 4 | 🏅 絆のお守り |
| 5 | ⚡ ハイブリッド特性 |
| 6 | 📚 趣味・教養 |
| 7 | ⚔️ 宿敵との共闘 |
| 8 | 👟 シグネチャーブランド |

定義は `src/data/generationUnlocks.js`。
上位転生（第2段階以降）を経ていれば周回数に関わらず全部開く。

### 解放モーダル

新しい周回が始まったとき、その周で解放された機能をモーダルで出す。
開いている間は時間が止まる。

各機能には **summary**（何ができるか1行）と **flavor**（なぜ今できるのか）を持たせた。
flavor はタイムリープの文脈で書く。新しくできることは
「前の人生で得た知識が形になった」結果でなければならない（§2）。

例（師弟継承 / 3周目）:
> 三度目になって、ようやく周りが見えるようになった。
> 一度目は自分のことで精一杯だった。二度目は追い抜くことしか考えていなかった。
> だが同じ時間を何度も繰り返していると、隣で伸び悩んでいる選手が、
> どこで躓いているのかが手に取るように分かってしまう。

未解放の機能名はタブのラベルにも出さない（「交流・師弟・お守り」→「交流」）。

## 22. ポジションと名前の扱い（v0.3 / 2026-11-23 実装）

> 「ポジションは**いつでも変えられる**ようにして、**転生時には名前もポジションも変えない**ようにしようか」

| 項目 | 以前 | いま |
|---|---|---|
| 選手名 | 転生のたびに変更できた | **変わらない**。システム設定からのみ変更 |
| ポジション | 転生時にしか選べない（「CF固定」） | **キャリア中いつでも変更できる**。試合・戦術タブから |
| 体格 | 転生時に選ぶ | そのまま（肉体は作り直されるので） |

タイムリープは同一人物が5歳に戻るだけなので、名前が変わるのはおかしい。
ポジションは逆に、本人の意思でいつでも変えられる方が自然。

ポジションを変えると `careerPosMatches`（POS別の出場数）が分散するため、
特性の永続習得（各POS 50試合）との間に自然なトレードオフが生まれる。

## 24. v0.35 の作り直し（2026-11-23・プレイフィードバック 第4弾）

### 24-1. 乗算の塊にソフトキャップを入れた

外側に足すと、またここだけが効く穴になる。

### 24-2. 引退は「ピークから何割落ちたか」で決める

旧: カテゴリ0まで落ちて、かつ総合力4.5未満。
→ 戦術眼が落ちにくいので総合力が6前後で下げ止まり、**71歳まで現役が続いた**。

新: 33歳以降、ピーク時の4割を切ったら契約が来ない。
現実でもそうなっている。最下層まで落ちるより先にオファーが止まる。

衰え緩和を積んだ人は低下そのものが遅いので、自然と長く現役でいられる。

### 24-3. 加齢は「能力値」ではなく「才能の器」を削る

能力値だけを削っていたら、AUTO練習が毎月それを取り返していた。
上限（`ageCapMult`）を落とせば、練習しても上限超過の逓減が効いて伸びない。
**衰えを「取り返せないもの」にする**のが要点。

### 24-4. 1周目は勝てない

本人が評価していた「1勝もできない惨めさ」が、v0.3 で失われていた。
試合戦力に1周目だけ ×0.42 を掛ける。進路選択でカテゴリは上がるが、試合では勝てない。

### 24-5. 上限超過の逓減を指数にした

「上限以上に能力が上がるのはいいが、減衰率をどんどんきつくしていくべき」（本人）。
双曲線 → 指数減衰。上限と同じだけ超過したら 1/4、2倍超過で 1/16。
積めば伸びるが、超過が進むほど加速度的に無意味になる。

### 24-6. 弟子は1つの人生で1人だけ

4人を順に選んで各5回訓練すれば、1つの人生で図鑑がコンプできていた。
一度指名したら変更不可。絆Lvも人生ごとにリセット（相手はこちらを覚えていない）。
`protegeBonds` は図鑑（最高到達Lv）の記録専用。図鑑を埋めるには最低4周かかる。

特訓は月1回まで。

### 24-7. 恋愛は段階制

旧: 1回 +10、40 で結婚。4回押せば終わる「クリック消化」。
新: 1回 +6、上限100、月1回まで。20/40/60/80/100 の節目で
相手ごとに違う出来事が起きる（`src/data/romanceEvents.js`、4人×5段階）。

節目には効果がつくが、派手なものは置かない（精神/体力の上限、戦術Pt）。
長く続けた人が少しずつ得をする形にする。

人生1回では100まで届かないこともある。「その人生ではそこまでだった」でよい。

### 24-8. 上位転生は何を差し出すか

継承結晶だけ失ってもゲノムが残っていたので、転生直後から強かった。
本人の要望は「ポンコツ状態にして、もう一度弱くなったけどさらに強くなるため頑張る」。

| 失う | 残る |
|---|---|
| 継承結晶・結晶強化 | 超越の聖杯・聖杯強化 |
| ゲノム・融合ゲノム | 隠しゲノム・進路アーカイブ |
| 地元クラブ（Lv/同僚/施設） | エンディング・試練・チャレンジ達成 |
| ポジションイベント・宿敵パークの上限ボーナス | それらを「見た」記録 |
| 装備中の特性・国際タイトル | 特性の解放記録・弟子と恋人の図鑑 |

ゲノムは能力値から自動で再解放される仕組みなので、鍛え直せば戻る。
＝「もう一度積み上げる」対象になる。

**聖杯の獲得量をその周回の積み上げに連動させた。**
条件を満たした瞬間に転生するのが常に最適、という状態をなくすため。
ピーク総合力・試合数・得点関与を 0.4 前後の指数で足す。
粘れば増えるが、粘りすぎても支配的にはならない。

### 25-6. 力量に合わない買い物

「2週目のまだ弱いときに個人スポンサーはつかない」。

| アイテム | 追加した条件 |

### 25-7. 宿敵は運で決まらない

「勝てる相手には絶対勝てるし、そうでない相手には絶対勝てない」。
確率の項を外した。能力が足りないうちは一度も勝てず、足りた瞬間から確実に勝つ。

### 25-8. やりこみ

- **継承結晶は使わず持っているだけでも効く**（対数。1万で+4.8%）
- **ひとつの能力を突き詰めると試合戦力が最大+45%**。満遍なく上げると一切つかない
- **桁違いのゲノムを9種**（10万ゴール / 100万勝 / 1億試合 / 50万守備出場 /
  1億回の反復 / 1万年の現役 / 1万人の師 / 一点突破の証）。
  前線固定の圧力にならないよう、守備・出場・練習量にも同じ重さで置いた
- **進路ゲノムの上限が上位転生で5倍・10倍**になる
- **装備枠は最初1つ、拡張を積みきると全部**（お守り7・特性9）

### 25-9. 4大リーグ以外

6か国を追加し、リーグの効果を **if 分岐からデータ（`effects`）へ移した**。
以前は france / italy / england だけが計算側に書かれていて、国を足しても効果が付かなかった。

| リーグ | 性格 | 稼ぎ |
|---|---|---|
| オランダ | 戦術眼+12% / 全上限+8 | ×0.82 |
| ポルトガル | 技術+14% / 決定+8% | ×0.86 |
| ベルギー | 賞金+8% / ファン+12% | ×1.08 |

**稼ぎは落ちるが、そこにしかないゲノムがある。** 各国に専用ゲノム（Lv5）と、
移籍時に一度だけ出るフレーバーを用意した。

### 25-10. エンディング本文の矛盾

13歳の選手に「最後の試合」「子どもの頃にテレビで見ていた場所」と表示されていた。

## 26. v0.4 — このゲームの芯（2026-11-28）

> 主人公はサッカーが好きでしょうがないが、全く才能がない。

> ただ、サッカーへの情熱とタイムリープの能力だけがある。
>
> リアルにシミュレーションをしたときに、全く才能のない人間が人生をやり直して
> サッカーに情熱を捧げて、どのぐらい上手くなるのか、どれぐらいの時間が必要なのか、
> どれぐらいの経験が必要なのかということを考えたときに、
> **本当に、ゲームの序盤は勝てない。ただ少しずつ勝てるようになっていく。
> ほんの少しずつ強くなっていく。タイムリープを行うごとにほんの少しずつできることが増えていく。**

### 26-1. 成長カーブをS字にした

才能ゼロの人間が同じ人生を繰り返しても、最初の数周で届く場所はたかが知れている。

```
8周目まで:  上限の土台 ×1.17/周   （ほとんど伸びない）
9周目から:  上限の土台 ×1.6/周    （積み上げた知識が効き始める）
```

| 周回 | 到達（実測 / 100倍速） |

| 7 | 大学 |
| 9 | 社会人リーグ |
| 11 | JFL |

### 26-2. 勝率が「少しずつ上がる」ようにした

v0.36 までは、相手の強さが **rating（能力値の合計）の0.62倍** を下限にしていた。
成長倍率・試合戦力倍率（ソフトキャップ後でも20〜50倍）が相手に一切反映されないので、
**実測で250試合248勝**になっていた。

相手は、こちらの出力（倍率込み）にある程度ついてくる形にした。

```
通常:        相手 = max(カテゴリ固有値, 自分の出力 × 0.74, rating × 0.5)
上位転生後:  相手 = max(カテゴリ固有値, 自分の出力 × 0.45, rating × 0.5)
```

**重要: 追随の基準は「周回係数を掛ける前の出力」。**
係数込みの値を基準にすると相手も同じだけ弱くなり、戦力比が変わらず
序盤の「勝てない」が消える（実測で5周目の勝率が59%になった）。

| 周回 | 戦力比 | 期待勝率 |
|---:|---:|---:|
| 1 | 0.30 | 1% |
| 3 | 0.51 | 5% |
| 5 | 0.77 | 18% |
| 7 | 1.08 | 40% |
| 9以降 | 1.35 | 58% |
| 上位転生後 | 2.22 | 83% |

実測でも 46〜58% に収まった。**無双は上位転生を経てから。**

### 26-3. テスト用の100倍速

`http://localhost:5173/?dev=inuyuna`（本番なら同じクエリを付ける）を一度踏むと、
そのブラウザに `football_chronicle_dev` が残り、以降ずっと 100x ボタンが出る。

- 1ティック（100ms）で10ヶ月進める。間隔を詰めると React の再レンダーが追いつかない
- 2回目以降の月はトーストを抑える（1ティックに10件飛ぶと画面が埋まる）
- **40秒で21周ぶん回せる。** バランス調整はこれで実機確認する

### 26-4. 速度と一時停止を残す

> 「リロードであるとか、タイムリープの何かの操作をしたときに、転生後に停止して
> 8倍速も解除されるような部分があるが、これは設定を残すなりして、
> 一度設定したらその設定から変わらないようにしてもらいたい」

速度と一時停止は `useState` だったので、リロードでも転生でも 1x に戻っていた。

自動選択は進路が発生した瞬間にしか判定していなかったので、
「モーダルが出ている状態で設定をONにする」と、そこで止まったままになっていた。

## 27. v0.41 — 半自動化と戦術Ptの供給（2026-11-29）

### 27-1. 「一度やりきったことは、次の人生では手がかからない」

> 「弟子の育成と結婚を半自動化（育ってきたら自動化されるように）して」

敏腕秘書（結晶で買う）に加えて、**過去の到達**でも自動になる。

| 要素 | 自動になる条件 |
|---|---|
| 弟子の指名と特訓 | 秘書Lv1 **または** 過去に絆Lv5まで育てた相手がいる |
| 恋愛（デート〜結婚） | 秘書Lv2 **または** 過去に結婚までいった相手がいる |
| スクール巡業 | 常に自動（`autoSocialRun` が ON なら） |

タイムリープの文脈とも合う。同じ相手と同じ出会い方をするのが何度目にもなれば、
どう接すればどうなるかは体が覚えている。

**弟子の自動指名は、図鑑がまだ埋まっていない相手を優先する。**
放っておくと4人を順に埋めていく形になる。

実測: 絆Lv5の相手が1人いる状態で18歳から回すと、
6年で別の弟子を絆Lv38まで育て、幼馴染と好感度100で結婚していた。

### 27-2. 戦術Ptが足りない

> 「スクール巡業をしないといろんな数字が良くならない
>  （購買するのに金なのか戦術ポイントが足りない）ようになってる」

戦術Ptの供給が `tactics_video` の練習とスクール巡業にほぼ限られていた。
道具も蒼空FCも無制限投資も戦術Ptを要求するので、巡業を回さないと何も買えない。

**試合に出ること自体を戦術眼の経験にした。**

```
1試合あたり = (1.8 + カテゴリ番号 × 1.4) × (勝1.6 / 分1.2 / 負1.0)
```

キッズで2〜3Pt、J3で16〜26Pt、W杯代表で25〜40Pt。月2試合。

実測で 1周目206Pt → 4周目1,165Pt → 7周目2,000Pt。巡業なしでも道具が買える。

### 27-3. スクール巡業のコストをカテゴリ連動に

固定（ファン400 / 15,000円）だったため、**序盤は一度も開けず**
（実測8周ぶんで通算0回）、終盤は安すぎて連打するだけになっていた。

```
ファン = 120 + カテゴリのfanGain × 0.8
資金   = 4,000 + カテゴリのbaseReward × 0.5
```

| カテゴリ | ファン | 資金 |
|---|---:|---:|
| キッズ | 120 | 4,400 |
| JクラブJY | 127 | 6,100 |
| J3 | 760 | 46,500 |
| J1 | 5,320 | 184,000 |

実測で4周目から自動で回り始めるようになった。
