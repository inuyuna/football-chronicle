**12周してカテゴリが1段も上がらない。** ピークの伸びは +8〜9/周の線形。
JFL（125）にすら12周で届かない。この傾きだと海外（850）は96周目あたり。

### 原因1: 成長が線形、必要値が指数

```
baseCap        6.2 → 7.0 → 8.1 → 9.2 → 10.3 …   足し算
カテゴリ必要値  58 → 82 → 125 → 195 → 310 → 500 → 850   掛け算
```

### 原因2: デッドロック

```
カテゴリが上がらない → 結晶が増えない → 強化できない → カテゴリが上がらない
```

結晶の獲得量は `catFactor = (categoryId + 1)^1.3` が支配項。
カテゴリが止まると獲得量も止まる。

### 🔴 重要: 1.7倍と2.0倍で最終到達がほぼ同じ

| | 9周目 | 12周目のピーク |
|---|---|---:|
| 1.7倍 | J2 | 760 |

**倍率を上げても9周目以降は J1 で頭打ちになる。**
つまり後半を止めているのは `baseCap` ではなく**別の要因**。

### 後半の律速は「結晶の経済」

上限突破（`cap_breaker`）が両方とも **Lv13 で止まっている**。
結晶残も常に数十個。つまり毎周、結晶を使い切っても1〜2Lvしか上がらない。

```
cap_breaker のコスト = 10 × 1.15^Lv
  Lv13 →    61
  Lv20 →   164
  Lv30 →   662
  Lv60 → 43,000
  Lv120 → 最大Lv。到達には累計で天文学的な結晶が要る
```

一方の獲得量は1周あたり60〜230程度。
**つまり `cap_breaker` の最大120Lv は事実上、到達不能な設定になっている。**

効果も `+2.0/Lv` 固定なので、Lv13 = 全上限 +26 にしかならない。
カテゴリの必要値が850、1500と伸びていく中では焼け石に水。

### 第2転生（Ascension）の解放条件が合っていなかった

旧条件:
```
ascReqCrystalLv = 60 + ascCount * 35   // 結晶強化の合計Lv
ascReqCatId     = 12 + ascCount        // 到達カテゴリ
```

実測では強化計Lvの伸びが **+2/周** なので、Lv60 到達は **27周目あたり**。
カテゴリ条件（cat12）は13周目に満たすのに、Lv条件が15周ぶん遅れて足を引っ張る。

本人の設計意図:
> 「第二転生を **J1から海外にいくタイミング** で行うようなバランスに」
> 「第三転生は、**海外トップリーグで活躍できるかできないかレベルから、
>   完全無双できるようになる段階**」

実測の J1 到達は10周目（Lv28）、欧州中堅は13周目（Lv33）。
そこで新条件:

```
ascReqCrystalLv = 28 + ascCount * 12
ascReqCatId     = 11 + ascCount
```

| 第2転生 | 11 J1 | 28 | 10周目 |
| 第3転生 | 12 欧州中堅 | 40 | （要計測） |
| 第4転生 | 13 欧州CC | 52 | （要計測） |
| 第5転生 | 14 W杯代表 | 64 | （要計測） |

第3転生が「欧州中堅＝海外トップで活躍できるか微妙なレベル」に当たるので、
本人の言う「そこから完全無双へ」と対応する。
